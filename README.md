# BUFF BATTLE

A meme-flavored, Brotato-style **mobile arena survivor** built with Flutter.

Survive 12 escalating waves of "haters", vacuum up XP orbs, and **get swole** —
your character visibly bulks up as it levels. Pick the fighter you vibe with:

- **CHEEMS (dog)** — fast, rapid bonks, glass-cannon energy.
- **BUFF CAT (cat)** — tanky, hits like a truck, unbothered.

## Gameplay

- **Move:** touch & drag anywhere — a floating joystick appears under your thumb.
- **Attack:** auto-fires at the nearest enemy. One-handed friendly.
- **Survive** each wave's timer. Clear the wave, heal up, fight on.
- **Level up:** collect XP orbs from kills, then pick 1 of 3 upgrades
  (`MUCH DAMAGE`, `VERY SPEED`, `WOW CRIT`, `MULTI BONK`, `VAMPIRE`, ...).
- Every 5th wave spawns a **boss**. Clear wave 12 to win.

Enemy types: **Hater** (basic), **Zoomer** (fast/fragile),
**Chonk** (slow tank), **Boss**.

## Running it

This repo ships the full game code (`lib/main.dart`) plus project config.
The native platform folders (`android/`, `ios/`, ...) are generated by the
Flutter toolchain rather than committed.

```bash
# 1. one-time: generate the platform scaffolding into this project
flutter create .

# 2. fetch dependencies
flutter pub get

# 3. run on a connected device / emulator
flutter run
```

Build a release APK:

```bash
flutter build apk --release
```

Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install)
(Dart SDK >= 3.0). No third-party packages — everything is drawn with
`CustomPainter`, so there are no image assets to manage.
