# BUFF BATTLE

A meme-flavored, **Hades-style mobile arena survivor** built with Flutter.
Pure `CustomPainter` rendering — no image assets, no third-party packages.

Clear 5 themed floors (25 waves), survive each wave timer, vacuum XP orbs,
spend Obols at Charon's shop, and **get swole** — your fighter visibly
bulks up as it levels.

## Classes

| Class | Role | Signature |
|---|---|---|
| CHONK KNIGHT | Tank | huge HP, **thorns**, `GROUND SLAM` |
| BOW DOGE | Archer | **piercing** arrows, `ARROW NOVA` |
| WIZARD CAT | Mage | **splash** damage, `METEOR` |
| DOOM PUG | Warlock | **poison + lifesteal**, `PLAGUE WIND` |
| NINJA SHIBA | Assassin | high crit/speed, `SHADOW DASH` |
| GANGSTA RAT | Gunner | rapid fire, `OVERDRIVE` |

## Systems

- **Move:** touch & drag — a floating joystick appears under your thumb.
- **Attack:** auto-fires at the nearest enemy (one-handed friendly).
- **Ability:** MP-gated active per class (bottom-right Cast button).
- **Boons:** XP level-ups offer 1 of 3 Common/Rare/Epic upgrades.
- **Doors:** Hades-style reward choice between waves
  (Treasure / Fountain / Boon / Arsenal / Overcharge).
- **Charon's shop:** after every floor boss — potions & permanent buffs.
- **Floors:** Backyard → Sewer → Caves → Factory → Void, each with its
  own palette and escalating enemy multipliers.
- Enemies: Hater, Zoomer (fast), Chonk (tank), Spitter (ranged, floor 3+),
  Boss (every floor end).
- Pause anytime (top-right), screen shake & low-HP warning for feedback.

## Running it

The native platform folders (`android/`, `ios/`, ...) are generated by the
Flutter toolchain rather than committed.

```bash
flutter create .     # one-time: regenerate platform scaffolding
flutter pub get
flutter run
```

Release APK: `flutter build apk --release`.
Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install)
(Dart SDK >= 3.6, i.e. Flutter >= 3.27 — uses `Color.withValues`).

## Play in a browser (iPhone-friendly)

CI publishes the Flutter web build to the `gh-pages` branch on every push.
One-time setup: repo **Settings → Pages → Source: Deploy from a branch →
Branch: `gh-pages` / `root`**. After the next green run the game is live at:

```
https://blackays.github.io/test/
```

Open that in mobile Safari/Chrome and play — touch controls work. (The
repo/code stays private; only this built page is publicly reachable. If the
repo is renamed, update `--base-href` in the CI workflow and the URL path.)

## CI

`.github/workflows/ci.yml` runs on every push: regenerates platforms,
`flutter analyze`, `flutter test`, then builds **web** and a **debug APK**
(uploaded as a build artifact). This is the automated compile gate.
